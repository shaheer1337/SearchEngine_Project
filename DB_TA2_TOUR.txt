COMP4321 TA2 DB Tour Script (2-3 minutes)
=========================================

Purpose:
- Quick spoken script + commands for TA2 (Indexing & DB station).

0) One-time compile (if needed)
--------------------------------
javac -cp .:htmlparser.jar:lib/jdbm-1.0.jar \
  IRUtilities/Porter.java StopStem.java Posting.java PageMetadata.java \
  DBManager.java Crawler.java Spider.java QueryParser.java SearchEngine.java \
  SearchMain.java PostingInspector.java DBViewer.java TestProgram.java

1) Posting-list inspector demo
------------------------------
Command:
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar PostingInspector run

Say:
- "This utility normalizes + stems the input term and prints posting lists."
- "For each matched document, it shows pageID, tf, and URL."
- "It prints body and title postings separately."

2) Stopword removal proof
-------------------------
Commands:
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar PostingInspector the
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar PostingInspector of
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar PostingInspector a

Expected:
- Removed by stop-word filter / not found in index.

3) Stemming parity proof
------------------------
Commands:
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar PostingInspector running
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar PostingInspector run

Expected:
- Same stem ("run"), same posting list output.

4) Separate body/title indexes + phrase support
------------------------------------------------
Command:
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar DBViewer 0

Point out:
- "forwardIndex" table (page -> wordID:tf map)
- "titleIndex" table (separate inverted index for title terms)
- "positions (from bodyIndex)" column, proving positional postings

Say:
- "Phrase search uses positional adjacency checks over stored positions."
- "Title and body are separate indexes, so title matches can be boosted."

5) Fresh hidden-seed re-index (N=30) without losing 300-page DB
----------------------------------------------------------------
Commands:
  cp searchengine.db searchengine_300.db
  cp searchengine.lg searchengine_300.lg
  rm -f searchengine.db searchengine.lg
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar Spider "<TA_HIDDEN_SEED>" 30
  java -cp .:htmlparser.jar:lib/jdbm-1.0.jar Spider "<TA_HIDDEN_SEED>" 30

After TA2 (restore 300-page DB for TA3):
  mv -f searchengine_300.db searchengine.db
  mv -f searchengine_300.lg searchengine.lg

Target:
- Finish under 1 minute.

6) DB schema short tour
-----------------------
Say:
- "One JDBM RecordManager with HTrees:"
- "URL<->pageID, word<->wordID, bodyIndex, titleIndex, forwardIndex,"
- "pageMetadata, parentLinks, childLinks, counters."
